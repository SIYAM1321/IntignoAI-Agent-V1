# IntignoAI Agent v1.10.0 — Release Notes

## Included

- NVIDIA NIM provider adapter for `z-ai/glm-5.3-flash`, including SSE streamed response text, function/tool calls, image input support where the endpoint accepts it, tool-result handoff, and per-model conversation history.
- GLM-5.3-Flash is the default. Gemini 3.5 Flash Lite remains selectable per message in the composer.
- GLM Think toggle maps to `reasoning_effort=max` (checked) and `low` (unchecked). NVIDIA's current GLM-5.3-Flash integration always reasons, so unchecked is a low-effort mode rather than a guaranteed no-reasoning mode.
- NVIDIA API-key setup in Settings. Secrets are read from local `.env` and are not embedded in this ZIP.
- Live expandable execution timeline in the chat, including tool/activity status and available inputs, outputs and errors; the former action approval bar is removed in favor of chat replies like `yes, proceed` / `no, cancel`.
- Headless embedded browser with live CDP screencast inside the Browser tab; automatic Browser tab switching when browser tasks begin; retry handling for the initial stream-start race.
- Embedded-only manual sign-in handoff; the agent doesn't deliberately open a physical OS browser. Site policies, CAPTCHA/MFA and provider headless-browser restrictions may require interaction in the embedded tab.
- Clipboard-pasted images are attached via the existing upload endpoint.
- Persistent browser-session liveness check fixed for Playwright's API; headless Chromium supports container/root launch where applicable.
- Prompt guidance for concise progress narration, append-only memory updates that note superseded preferences, and documentation-led setup of unfamiliar languages/runtimes.

## Configure

1. Extract the ZIP.
2. Copy `.env.example` to `.env` if you prefer environment-file configuration (or use Settings).
3. Set `NVIDIA_API_KEY` for the default GLM model. Set `GOOGLE_API_KEY` only if you also want to use the Gemini model.
4. Start via `start.sh` (macOS/Linux) or `start.bat` (Windows), then open `http://127.0.0.1:2000`.

Never include `.env`, API keys, browser profiles, or local chat databases in a ZIP shared with others.

## Known limitations

- NVIDIA/Gemini live API calls were not made during local tests. The GLM adapter was tested using mocked streamed responses and mocked native tool-call chunks.
- No universal login or scraping success can be guaranteed. Some sites block headless sessions, require MFA/CAPTCHA, apply rate limits, or prohibit automation. Complete legitimate verification in the embedded Browser tab when needed; the agent does not bypass those safeguards.
- Compiler/runtime installation depends on OS support, package-manager access, network availability and the requested language's licensing and platform support.
