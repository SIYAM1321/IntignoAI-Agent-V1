# IntignoAI Agent v1.9.1

This is an incremental upgrade of v1.9.0, not a guarantee of success on arbitrary sites or languages.

- Removes the separate manual browser sign-in icon; users interact via embedded Browser tab. Existing legacy backend sign-in routes remain for compatibility (some providers require a standalone, disconnected browser for authentication).
- Adds a visible black pointer overlay that follows the user in the embedded Browser tab. The pre-existing Playwright `mouse_click`/`mouse_move` actions are available to the agent for coordinate-based fallback and the embedded tab already supports manual CDP click, scroll and typing. The overlay is visual feedback for manual interaction, not a hardware mouse or an agent-position telemetry feed.
- Adds explicit OS-aware full-stack development, testing, browser verification and requested-port deployment workflow instructions. No automatic cross-platform test matrix was run.
- Keeps required confirmations for consequential actions; does not pause for ordinary steps, provided models invoke tools.
- Project dependencies and runtime SDKs must already be installed or be installable. Some websites block automation or require human authentication.
- For distribution, local `.env` / database and previously generated user data are excluded to prevent credentials or personal data leakage. Copy `.env.example` to `.env` and configure your API key.
